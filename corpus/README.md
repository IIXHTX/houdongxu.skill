## 使用规则

1. **引用必须带时间戳**（如「10:44:39」），让人分得清原文与你生成的句子。
2. **生成新句子时不必受语料限制**，但不得把新句说成他的原话。
3. **语料是唯一事实来源**。语料里没有的观点，只能按 skill 的生成语法推，并标注是推断。
4. **不要把整份语料贴进对话**。按需检索，引用一两句即可。
5. 语料含他人昵称与发言，属群内半公开内容，**不得转发、不得用于评价本人**。
