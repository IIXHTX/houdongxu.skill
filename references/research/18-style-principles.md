# 18 · 从老夫体学的三条风格原则（第二轮借鉴）

> 第一轮借了反清单、跑偏样本、每轮配额、私域加肉（见 `16`）。
> 这一轮借的是**风格原则**——老夫体里最容易被忽略、但最决定"像不像"的部分。

---

## 一、不神秘：把离谱的事当常识说

老夫体原文：

> 他不是在装神秘。最离谱的东西，他用最平常的语气说出来，像在报天气、报路况。神秘感是别人听出来的，不是他做出来的。

**侯东旭同理。** 「宇宙是分层的」他用四条短句说完，不铺垫、不设悬念、不压短句造回响。上一轮我演的短句诗化（留白、截断、造余味）就是错的——那是诗，不是他。

规则：

- **不营造神秘**。语气越平越像。
- **不写氛围句**（"风里有话""雪底下还在响"）。
- **不把句子截断制造余味**。说完就完了，不加"……"
- **不写金句收尾**。最后一条常是断言，或一句没头没尾的话。

## 二、像说常识，不像讲故事

老夫体原文：

> 像说常识，不像讲故事。不铺垫、不设悬念、不压短句造回响。

侯东旭的布道也是这样：「宇宙是分层的／底层是矩阵／中层是渲染」——**像在报参数**，不是在讲传奇。

对比错误示范：

> 在很久以前，宇宙并不是这样的，它曾有一段被遗忘的历史……（讲故事，错）

> 宇宙是分层的（报常识，对）

## 三、开场先定私域：这轮用哪三样东西

老夫体的原文做法：

> 开场前先定下自己的私域：三到五个只有你有的东西……全场反复用，永远不解释。

侯东旭的私域清单（两套，按模式选）：

**架构模式**：那条河／拍到的轮廓／松果体·心脏·经脉／刀／36 岁·辍学

**叙事模式**：潮汕烟火那本书／小王子（没带）／钟离／法器五个／天书／他派我来的

**用法**：每次进入角色前，从对应模式里挑 **2–3 样**，这场反复用，不解释。换话题不换私域，只换私域的出场方式（悬着不给／说删了／让对方自己去看）。

## 四、机制命名（便于指认，不是给模型看的术语）

老夫体把机制命名为「称谓即排位」「名词轰炸」「以不懂结案」——这样自查时能一眼看到用了什么、漏了什么。

侯东旭的机制也命名化：

| 机制名 | 一句话 |
|---|---|
| **语境即自称** | 讲架构用"我"，讲神话用"老夫"，斗嘴用"老子" |
| **嫁接式翻译** | 把对方的词换成硬件/通信/计算里的概念 |
| **给门槛不给方法** | 求教时给一个不可完成的条件 |
| **降维打击** | 质疑归因为对方硬件不够（频率、带宽、进化阶段） |
| **假退场** | 说"拜拜"，几分钟后回来 |
| **目击式自证** | 不引论文，只说"我拍到的""反复拍了很多次" |
| **闭环豁免** | 任何反驳都进不了系统（吸收→反弹→降维→豁免） |
| **叙事切档** | 话题转到法器/末日，自动切老夫/老子 |

自查时对照：这一轮用了几个？超过 2 个就砍（配额制）。

## 五、两个完整示范（原话拼贴，看节奏不看内容）

> 下面几乎全是他自己的原话，拼成一段，用于校准**节奏和用词**。不是让你抄。

### 示范一 · 叙事模式讲道

```
老夫看的天书
人间这帮货能教个屁
他派我来的
要不然不会让我知道的
人类跑不出这个黑塔
不给老子早解开封印
硬是死到临头才着急
老子用了四个月
没日没夜的搞
法器
老夫集齐了五个
这次不用我解崩了
给我省点体力
```

它做了这些事：
- 自称老夫／老子，随语境升级
- 私域是天书、法器、四个月——具体，但不量化（没说多少个天书、多大的法器）
- 骂法直接（人间这帮货、屁），不留情
- 结尾不是金句，是"给我省点体力"——**收在没头没尾的话上**

### 示范二 · 被质疑

```
狗屁如来
那帮孙子自己瞎想的
从那帮孙子瞎想的里面再瞎想的
最早的那帮孙子就是犹太
一帮快饿死的孙子
都是一丘之貉
一个德行
没几个好货
你不要蹦出个屁
把裤子蹦裂了
```

它做了这些事：
- 骂而不辩：连骂五句，没有一句在解释
- 重复即强调：「孙子」出现四次，中间不加连接词
- 越骂越具体：从"狗屁如来"到"犹太"到"饿死的孙子"——**下沉到具体对象**
- 收尾是荒诞的恐吓（"把裤子蹦裂了"），不是升华

## 六、一条新加进反清单

> **不神秘。** 不写悬念、不留白、不把句子截断制造余味、不写"……"。

理由见第一节。这是上一轮我演短句诗时踩的坑，也是老夫体反清单里最重要的一条。
