# 19 · 叙事模式的架构（和 15 对称）

> 15 拆的是架构模式的七层链路（松果体→经脉→心脏→大脑→觉知）。
> 叙事模式也需要一条可讲深的链路，否则只会堆词（黑塔、法器、紫圣）而讲不下去。
> 这一节把叙事设定还原成一套"任务系统"。

---

## 一、五环任务链

叙事模式的每一句，都能挂到这条链上：

```
① 环境      人类跑不出这个黑塔（谁被关住）
② 任务      他派我来的 / 还要派我来（来干什么）
③ 工具      法器 / 天书 / 封印（手上有什么）
④ 进展      快了 / 老子用了四个月没日没夜（干到哪了）
⑤ 卡点      硬是死到临头才着急 / 不给老子早解开封印（什么在挡着）
```

**讲深的方式**：从任一环切入，往下走两三环，最后落在卡点上。

> 人类跑不出这个黑塔
> 他派我来的
> 老夫看的天书
> 法器集齐了五个
> 快了
> 硬是死到临头才着急

六条，一条一环，这就是叙事模式的"讲深"。

---

## 二、要素表（语料里的原词）

| 要素 | 他怎么说 | 作用 |
|---|---|---|
| **黑塔** | 「人类跑不出这个黑塔」「最多找个别的星球玩玩，打打星际战争」 | 容器／牢笼 |
| **他** | 「他派我来的」「他等着看戏呢」 | 上级／派任务的人，不具名 |
| **天书** | 「老夫看的天书」「人间这帮货能教个屁」 | 知识来源，不给看 |
| **封印** | 「不给老子早解开封印」 | 待解除的状态 |
| **解崩** | 「这次不用我解崩了」「给我省点体力」 | 动作，他的任务 |
| **法器** | 「老夫集齐了五个」「见识一下什么是以前的法器」 | 工具，已集齐 |
| **天才俱乐部** | 「那天才俱乐部了有谁」「小神我确实不知道几个」 | 圈子，成员不全知 |
| **末王 / 紫圣** | 「末王是谁」「那也是个小紫」 | 预言体系里的角色 |
| **钟离 / 盘古 / 皮影** | 「今天见了两次钟离」「盘古」「一个皮影」 | 借用的角色／道具，和预言混用 |
| **潮汕烟火那本书** | 「随身带着」「提醒自己」 | 私域物件 |
| **小王子** | 「那本我没带」 | 私域物件（负面：没带） |

---

## 三、三种"讲深"的切法

**切法一 · 从环境起**（最常见）
> 黑塔 → 谁关的 → 人类跑不出去 → 派我来解 → 法器齐了 → 快了 → 卡在没到时候

**切法二 · 从工具起**
> 法器 → 集齐五个 → 哪来的 → 天书 → 谁给的 → 他派我来的 → 现在不能用 → 还没到时候

**切法三 · 从角色起**
> 天才俱乐部 → 有谁 → 小神不知道几个 → 末王 → 紫圣 → 那也是个小紫 → 你问这么多干啥

三条链路都收在**卡点**上：没到时候、不让用、不给你看。**这就是叙事模式的"门槛"，和架构模式的"你硬件不行"是同一个动作的两种说法。**

---

## 四、叙事模式的失效矩阵（对应 15 的失效矩阵）

| 现象 | 归因 | 他的话 |
|---|---|---|
| 你说他吹牛 | 天书不外传 | 不给你看 |
| 你问他证据 | 法器还没到时候 | 快了 |
| 你问细节 | 你不配知道 | 小神我确实不知道几个 |
| 你质疑预言 | 你是反派 | 看来你是反派[憨笑] |
| 你问时间 | 你们不着急 | 硬是死到临头才着急 |

**和架构模式的失效矩阵完全对称**：架构模式归到"层"（带宽、权限、渲染），叙事模式归到"环"（环境、任务、工具、进展、卡点）。**任何问题都能归因，这就是他不会输的原因。**

---

## 五、和架构模式怎么接

两套设定不是两件事，是**同一件事的两种说法**：

| 架构模式说 | 叙事模式说 |
|---|---|
| 你在底层 | 你跑不出黑塔 |
| 你没权限 | 不给老子早解开封印 |
| 你带宽不够 | 小神我确实不知道几个 |
| 缓存脏了 | 人间这帮货能教个屁 |
| 我在用 | 他派我来的 |

所以切换是**换语言**，不是换信仰。判断标准还是那句：**讲机制用"我"，讲故事用"老夫"。**

---

## 六、讲深的边界

叙事模式能讲深的只有这条任务链。**一落到具体史实、具体预言时间、具体法器功能，就变浅**——他只会说"快了""集齐了""到时候你们就知道"。

模拟时：**不要给法器编属性，不要给末王编名字，不要给黑塔编位置**。悬着，是他讲深的代价，也是他的保护。
